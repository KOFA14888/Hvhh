# Hvhh

Исходники из архива находятся в `xevilight_internal/internal/`. Меню в
`jni/src/ui/xevilight/menu.hpp` использует стандартные элементы Dear ImGui;
кнопка Open menu остаётся доступной после закрытия окна. Выбор скинов теперь
представлен списком, без прежнего рисованного интерфейса галереи.

## Проверка интерфейса

На машине с `g++` и Python 3:

```sh
cd xevilight_internal/internal
python3 checks/verify_standard_menu.py
```

Это headless smoke-тест элементов и открытия/закрытия меню, а не проверка на
устройстве. Старый `verify_gui.py` относится к другому меню (kazakh).

## Ограничения сборки

Архив не содержит `jni/src/core/bypass.hpp` и `jni/src/core/bypass.cpp`, хотя
`entry.cpp` и `Android.mk` на них ссылаются. Кроме того, здесь нет Android SDK
и NDK. Поэтому нативная библиотека не собрана и её работоспособность на
устройстве не подтверждена. Для сборки нужны недостающие исходники и Android
NDK; ABI проекта — arm64-v8a, минимальный Android API — 23.

В архиве нет Android-проекта инжектора (manifest, исходников и Gradle build
файлов) или готового APK. Есть лишь исполняемый файл `inject/vpnService` и
текстовая инструкция, ссылающаяся на отсутствующий `inj.sh`. Готовый APK
инжектора в этом репозитории не создан.
