# Hvhh

Исходники из архива находятся в `xevilight_internal/internal/`. Меню в
`jni/src/ui/xevilight/menu.hpp` использует стандартные элементы Dear ImGui;
кнопка Open menu остаётся доступной после закрытия окна. Выбор скинов теперь
представлен списком, без прежнего рисованного интерфейса галереи.

## Проверка интерфейса

На машине с `g++` и Python 3:

```sh
cd xevilight_internal/internal
python3 checks/verify_standard_menu.py
```

Это headless smoke-тест элементов и открытия/закрытия меню, а не проверка на
устройстве. Старый `verify_gui.py` относится к другому меню (kazakh).

## Сборка и запуск

GitHub Actions собирает ARM64 библиотеку и debug APK, публикуя APK в Releases.
Инжектор запускает внедрение в работающий `com.axlebolt.standoff2` и требует root;
нужны ARM64-устройство и Android 23 или новее. Проверка на реальном устройстве
не проводилась, совместимость с конкретной версией игры не подтверждена.

Инжектор использует готовый двоичный `inject/vpnService` (AndKittyInjector) без
изменений; APK только копирует его и `libastra.so` в приватный каталог и
запускает с `--package com.axlebolt.standoff2 --libs libastra.so --memfd`.

В исходном архиве отсутствовали `bypass.hpp` и `bypass.cpp` — модуль скрытия
инжекта. Он не восстановлен, поэтому скрытность инжекции не обеспечивается.
Расширение средств обхода защиты живой мультиплеерной игры в этот проект не
входит; используйте только там, где у вас есть разрешение владельца приложения.

Что делает инжектор при запуске: запрашивает root, проверяет, что целевой процесс
запущен (`pidof`), копирует `injector` и `libastra.so` в `/data/local/tmp/hvhh-injector`
и запускает внедрение. Вывод root-команд и код возврата показываются в приложении.
